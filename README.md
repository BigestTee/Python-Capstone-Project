# Tee's African Kitchen - Menu Ordering System

## Project Description

Tee's African Kitchen Menu Ordering System is a simple Python-based
ordering application created as a capstone project.

The system allows customers to view the menu, place orders, view their
orders, update an existing order, delete an order, and exit the program.

The project demonstrates the use of basic Python programming concepts
and CRUD operations.

## Features

- View the restaurant menu
- Place a new order
- Add multiple items to an order
- View existing orders
- Update an order quantity
- Delete an order
- Calculate the total order cost
- Validate customer input
- Handle invalid input using error handling
- Exit the application

## CRUD Operations

### Create
Customers can create a new order by selecting items from the menu and
entering the quantity.

### Read
Customers can view the restaurant menu and their existing orders.

### Update
Customers can update the quantity of an existing order.

### Delete
Customers can delete an existing order.

## Python Concepts Used

- Dictionaries

- Functions

- Try/except error handling
- `append()`
